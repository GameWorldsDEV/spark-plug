# Spark Plug community profiles

This directory is the future GitHub-first library for free, editable Spark Plug
profiles. A profile is declarative configuration, never executable plug-in
code.

Before the first profile is accepted, the contribution workflow will validate:

- the setup-profile schema;
- engine and model revision pins;
- checksums, provenance, and licenses;
- declared memory, queue, route, and permission requirements;
- absence of scripts, commands, credentials, secrets, private paths, prompts,
  outputs, and user data; and
- human-readable review and risk notes.

Anyone may propose a profile through a pull request. Approved profiles remain
free to inspect, download, edit, and redistribute under their stated licenses.
No Spark Plug account, paid tier, marketplace checkout, or creator payout is
required.
