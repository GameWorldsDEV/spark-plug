# Supporting Spark Plug

Spark Plug currently accepts optional, pay-what-you-want support through the
GameWorlds Stripe account:

- Public link: <https://buy.stripe.com/aFa5kC2AQ6Jg3aj4UKdMI00>
- Suggested amount: USD $5
- Allowed range: USD $1–$1,000
- Frequency: one-time

Support does not buy software, features, priority, access, governance rights, or
service commitments. It is not represented as a tax-deductible charitable
donation.

The GameWorldsDEV GitHub Sponsors application has been started but is not public
yet. Do not advertise GitHub Sponsors as available until GitHub identity,
two-factor authentication, payout onboarding, profile review, and publication
are complete. Once the profile is live, add `github: [GameWorldsDEV]` to
`.github/FUNDING.yml` and change the public website status.
