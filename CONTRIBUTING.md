# Contributing to Spark Plug

Spark Plug is a free, open-source community project. Issues, documentation,
tests, accessibility improvements, platform packaging, reviewed engine work,
and declarative profiles are welcome.

## Before opening a pull request

1. Read `docs/PUBLIC_BOUNDARY.md`, `docs/PRODUCT.md`, and
   `CODE_OF_CONDUCT.md`.
2. Do not copy private history, screenshots, configuration, data, or assets.
3. Do not include credentials, prompts, outputs, node addresses, local paths,
   model weights, logs, or personal data.
4. Keep local operation independent from accounts, subscriptions, hosted
   entitlements, telemetry requirements, and financial support.
5. Run the validation commands in `README.md`.

Use focused commits and explain the behavior or public contract being changed.
New compatibility claims require evidence. New dependencies require a reason
and license/security review. Community profiles must also follow
`profiles/README.md`.

By contributing, you agree that your contribution is licensed under Apache
License 2.0. Security reports must follow `SECURITY.md`, not a public issue.
