# Contributing to Spark Plug

Spark Plug is preparing its first public software release. Contributions to the
public website, documentation, schemas, tests, and clean-room contracts are
welcome after an issue establishes scope.

## Before opening a pull request

1. Read `docs/PUBLIC_BOUNDARY.md` and `docs/PRODUCT.md`.
2. Do not copy source, history, screenshots, configuration, data, or assets from
   a private Spark Plug repository or installation.
3. Do not include credentials, prompts, outputs, node addresses, local paths,
   model weights, logs, or personal/customer data.
4. Keep the Community local core independent from hosted accounts and paid
   entitlements.
5. Run the validation commands in `README.md`.

Use focused commits and explain the product behavior or public contract being
changed. New claims require test or release evidence. New dependencies require
a reason and license/security review.

Security reports should follow `SECURITY.md`, not a public issue.
